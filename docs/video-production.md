# Demo Video Production

This document is the source of truth for the NekoSpace Binaural demonstration
video. The goal is a reproducible edit while keeping recordings and generated
voice files out of the public repository.

## Asset boundary

Private or generated media is ignored globally:

- Common audio and video formats are ignored globally, including WAV, FLAC,
  AIFF, M4A, MP3, MP4, MOV, MKV and WebM.
- `video/public/` contains the local source video and generated narration.
- `video/out/` contains rendered deliverables.
- Only Remotion code, text, timing and build metadata are versioned.

Never add an exception for a production recording. A deliberately generated
test fixture needs one narrow, reviewed `!path/to/fixture` rule.

## Storyboard and script

The video must answer three questions before demonstrating controls:

1. What is it? A binaural spatializer for headphones.
2. What goes in? A mono voice or sound effect.
3. What can the user control? Direction, elevation and distance.

Do not promise universally unambiguous vertical localization. Elevation is
described as an acoustic image or cue because perception depends on the listener,
headphones and source material.

| Composition time | Picture / caption | Narration |
| ---: | --- | --- |
| 0.0-4.0 s | `NekoSpace Binaural` / `声を、耳元の空間へ。` | ネコスペース・バイノーラル。 |
| 4.0-12.0 s | `モノラル音源をヘッドフォン向け立体音響へ` / `方位・高さ・距離を直感的に操作` | モノラルの声や効果音を、ヘッドフォン向けの立体音響へ変換します。方位、高さ、距離を、画面上で直感的に動かせます。 |
| 12.0-15.8 s | Left-position operation | 音源を左へ動かすと、左耳側へ定位します。 |
| 16.3-25.8 s | Right-position operation | 右へ動かすと、音像も右耳側へ移動します。 |
| 26.2-31.0 s | Positive elevation operation | エレベーションを上げると、上方向の音像を試せます。 |
| 31.5-45.5 s | Negative elevation operation | 下げると、下方向の手がかりへ切り替わります。 |
| 46.0-68.5 s | Near-distance operation | 距離を近づけると、囁きや声を耳元へ近づけたような表現になります。 |
| 69.1-73.1 s | Closing label and required voice credit | None |

The closing label is `Voice / ASMR / Audio Drama / Sound Effects`. The title
card and closing label say `Headphones Recommended`; binaural differences must
be evaluated on headphones.

## Narration

Narration is generated by the locally installed VOICEVOX engine.

- Voice: `VOICEVOX:猫使アル`
- Style: `おちつき`
- VOICEVOX speaker ID: `56`
- Output: 48 kHz stereo WAV
- Credit shown in the final video: `音声：VOICEVOX:猫使アル`

VOICEVOX and the character voice each require their terms to be followed. The
credit string above is mandatory for this video. Check the current terms again
before publishing a later commercial release.

| Start | Narration |
| ---: | --- |

| 16.6 s | 右へ動かすと、音像も右耳側へ移動します。 |
| 26.4 s | エレベーションを上げると、上方向の音像を試せます。 |

| 46.2 s | 距離を近づけると、囁きや声を耳元へ近づけたような表現になります。 |

Each sentence or paragraph is a separate WAV. This keeps a wording or
pronunciation change from shifting every later cue. During narration the
demonstration audio is ducked; between sentences it returns to full level so the
binaural movement can be heard without speech over it. The introduction has no
demonstration audio underneath it.

## Commands

With the VOICEVOX engine running at `http://127.0.0.1:50021`:

```console
cd video
npm run narration
npm run lint
npx remotion render NekoSpaceBinauralDemo out/NekoSpace_Binaural_demo_final.mp4
```

Review the rendered MP4 with headphones. Confirm that it contains a stereo AAC
track, captions match the visible controls, narration does not mask the movement,
and the VOICEVOX credit is legible before publishing.

## Reverb preset demonstration

The Reverb demonstration is a separate composition so the published Binaural video remains
reproducible and unchanged.

- Composition ID: `NekoSpaceReverbDemo`
- Private source recording: user-local capture, deliberately not named or tracked here
- Local cut: `video/public/NekoSpace_Reverb_demo_cut.mp4`
- Output: `video/out/NekoSpace_Reverb_demo_final.mp4`
- Size: 1360 x 884, 30 fps
- Structure: 10-second introduction, 86-second operation montage, 5-second credit card

The montage keeps Default and each factory preset for six to seven seconds, then demonstrates
Tail Only, Room Body, Mix 100%, ER Solo, Wet Mono Input and Reset. Long tool-operation waits
from the 473-second source recording are intentionally removed. The source and cut remain
ignored private media; only narration text, captions, timing and composition code are tracked.

The current loop recording is the short **feature tour**: its regular rhythm makes fast
preset comparisons easy. A later **sound-quality demo** should use two separately cleared
sources: an owned, CC0 or otherwise licensed classical-style piano/strings passage for Hall,
Decay and Tail, plus owned voice material for the product's main use case. An old composition
is not enough by itself; the particular performance and recording must also be cleared.

With VOICEVOX running locally:

```console
cd video
npm run narration:reverb
npm run lint
npx remotion render NekoSpaceReverbDemo out/NekoSpace_Reverb_demo_final.mp4
```
